# Photogen

Минималистичный фоторедактор с генератором ASCII логотипов.

## Запуск

**Windows.** Скачайте `Photogen.exe` из раздела Releases и запустите. Установка не нужна.

**Linux, macOS.** Откройте `index.html` в любом современном браузере (Chromium, Firefox). Работает так же, как exe, без сервера и интернета.

## Редактор

Инструменты: рука, рамка, кисть, ластик, фигуры (прямоугольник, эллипс, линия, стрелка), текст, пипетка.
Поворот и отражение, 13 параметров коррекции, кривые с гистограммой, 12 фильтров, история шагов,
сравнение до и после, масштаб и перемещение по холсту, изменение размера, экспорт в PNG, JPG, WEBP.

## ASCII логотип

Логотип из изображения или из текста. 8 стилей, 8 наборов символов, удаление фона, контуры, дизеринг,
окраска цветами изображения, градиентом или спектром, свечение.
Экспорт: копирование текста, PNG, SVG, HTML, TXT, ANSI.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| H, C, B, E, U, T, I | Рука, рамка, кисть, ластик, фигуры, текст, пипетка |
| Пробел | Временно перемещать холст |
| \ (удерживать) | Сравнить с оригиналом |
| [ и ] | Размер кисти |
| Ctrl+Z, Ctrl+Y | Отменить, повторить |
| Ctrl+Плюс, Ctrl+Минус, Ctrl+0, Ctrl+1 | Масштаб: больше, меньше, по окну, 100% |
| Ctrl+O, Ctrl+S | Открыть, сохранить |
| Enter, Esc | Применить или отменить обрезку |

## Структура

```
index.html, css/, js/     интерфейс и обработка изображений
  js/editor.js            движок редактора
  js/ascii.js             движок ASCII
  js/app.js               связка интерфейса
host/                     оболочка exe на C# (.NET 10, WebView2)
```

## Сборка exe

Нужен .NET 10 SDK:

```
dotnet publish host -c Release -o dist
```
